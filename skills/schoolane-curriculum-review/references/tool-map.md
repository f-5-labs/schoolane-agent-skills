# Curriculum review tool map

| Tool | Review use |
| --- | --- |
| `get_my_school_context` | Establish role, school, scopes, and current curriculum mode. |
| `academics_list_classes` | Resolve one permitted class. |
| `search` | Find the term and subject by name. |
| `fetch` | Read details for a returned search result. |
| `curriculum_get_term_scheme` | Audit scope, term dates, chain revision/status, editability, and rows. |
| `curriculum_list_lesson_plans` | Audit lesson numbers, duration, status, revision, and content for a scheme item/class. |

Forbidden in this read-only skill:

- `curriculum_save_term_scheme_draft`
- `curriculum_save_lesson_plan_draft`

Formal submission, review, approval, publishing, delivery, and student analysis are not registered tools.
